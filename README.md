
# 🎬 MeuTube - Plataforma de Vídeos Profissional

## CFO da Alma e dos Negócios

Uma plataforma moderna e completa de vídeos, inspirada no YouTube e Netflix, criada para hospedar cursos, tutoriais e conteúdos exclusivos.

## 🚀 Funcionalidades

### ✅ Implementadas
- 🎥 **Player de Vídeo Completo** - Reprodução de vídeos MP4 com controles nativos
- 📺 **Lista de Vídeos Relacionados** - Carrossel lateral com todos os vídeos
- 💬 **Sistema de Comentários** - Adicione e gerencie comentários em cada vídeo
- 👍 **Sistema de Curtidas** - Curta seus vídeos favoritos
- ❤️ **Favoritos** - Salve vídeos para assistir depois
- 🔍 **Pesquisa** - Busque vídeos por título, descrição ou categoria
- 📤 **Compartilhamento** - Compartilhe vídeos com Web Share API
- ➕ **Adicionar Vídeos** - Modal completo para adicionar novos vídeos
- 📱 **Design Responsivo** - Funciona perfeitamente em desktop, tablet e mobile
- 💾 **Persistência Local** - Dados salvos no localStorage do navegador
- 🎨 **Design Moderno** - Interface escura profissional com animações suaves

### 🎯 Próximas Funcionalidades (Futuro)
- 🔐 Sistema de Login/Cadastro
- 📚 Área de Cursos com Progresso
- 📊 Dashboard de Estatísticas
- 🎬 Upload de Vídeos direto na plataforma

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Grid, Flexbox, Animações, Variáveis CSS
- **JavaScript ES6+** - Classes, Arrow Functions, LocalStorage API
- **Font Awesome** - Ícones profissionais
- **Local Storage** - Persistência de dados
